Algorithm Design & Analysis

Sixteen algorithms. Six core topics. One documented Python collection.

Download source ↓Full READMEChanges

Getting started

Python 3.9+ recommended. No external dependencies. Extract the download, open its folder and run:

python main.py
python -m unittest discover -s tests -p test_correctness.py -v

The main runner prints sample outputs and theoretical complexity labels. It is a demonstration, not a benchmark. A separate assertion suite checks representative outputs and the Prim regression.

Algorithm reference

FunctionInput → outputComplexity and assumptions
merge_sortComparable sequence → sorted sequenceO(n log n); not stable for equal tagged keys
quick_sortComparable sequence → sorted listAverage O(n log n), worst O(n²)
binary_searchAscending sorted sequence, target → index or −1O(log n)
interpolation_searchAscending numeric sequence, target → index or −1Average O(log log n) for uniform data, worst O(n)
knapsackInteger weights, values, capacity W → maximum valueO(nW) time and space; 0/1 choices
fibonacci_memoNonnegative integer n → Fibonacci numberO(n) states, unit-cost arithmetic
primUndirected weighted adjacency dictionary, start → MST edgesO(E log E); start component only
kruskalNodes, (u,v,weight) edges → minimum spanning forestO(E log E) sorting plus union-find
dfsAdjacency dictionary, start → reachable vertex setO(V+E), recursive
bfsAdjacency dictionary, start → reachable vertex setO(V+E); duplicate queue entries may use O(E) memory
bellman_fordEdge list, vertex count, source → distance listO(VE); no negative-cycle detection
dijkstraWeighted adjacency dictionary, source → distancesO((V+E) log V) for simple graphs; nonnegative weights
floyd_warshallSquare distance matrix → all-pairs distancesO(V³) time, O(V²) space
coin_change_greedyPositive integer denominations, amount → coin listO(c log c+k); not always optimal or exact
huffman_codingText → character-to-bit-string dictionaryO(n+k log k) construction, plus emitted code lengths
hanoiPositive integer n and three peg labels → move listO(2ⁿ) time and output space; n=0 unsupported

Example

from algorithms.sorting import merge_sort
from algorithms.dp import knapsack

assert merge_sort([3, 1, 2]) == [1, 2, 3]
assert knapsack([2, 3, 4], [3, 4, 5], 5) == 7

Source and limitations

Original uploaded Python files are preserved under original/. The runnable package restores the folder structure and corrects Prim’s handling of repeated heap candidates. Full changes and input requirements are in the README and changelog.

These implementations are educational and have limited input validation. Negative cycles are not detected, greedy coin change is not a general optimal solver, and recursive routines can reach Python’s recursion limit.
