# Portfolio website setup

The portfolio files are in the repository root. To publish this repository as a project website, open Settings → Pages, select Deploy from a branch, main, / (root), then Save. Once deployed its expected URL is https://pouria-b.github.io/pouria-b/.

For a personal domain at https://pouria-b.github.io/, create a repository named pouria-b.github.io and copy these website files there, or rename this repository (renaming would remove the special profile README behavior).

Add future courses under courses/<name>/, document them, and add their entries to courses.json. Update index.html for profile changes. No third-party dependencies or build step are needed.

Course code and tests: see courses/algorithms/README.md. Original uploaded source is retained under courses/algorithms/original/.
