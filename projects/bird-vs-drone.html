Bird vs. Drone Detection

Designing and developing an object detection system using a pretrained YOLO model.

Grade: 19.75 / 20 · Advisor: Dr. Tabatabaei

Objective

Fine-tune a pretrained detector to distinguish birds from drones in video-derived images.

Approach

  1. Prepare video frames and correct class labels.
  2. Fine-tune YOLOv8s and compare three training experiments on an NVIDIA T4 GPU.
  3. Evaluate object detection performance.
  4. Export models to ONNX.

Evaluation considerations

Frames from the same video can be similar. Overlap across dataset splits was investigated, and limitations in evaluation on unseen videos were identified. Results from frame-level splits should be interpreted in that context.
